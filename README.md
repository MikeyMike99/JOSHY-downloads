# JOSHY Downloads

JOSHY is a Windows audio playback suite and Spotify controller built for blind and visually impaired users. It supports NVDA, JAWS and Narrator, audio earcons, and full keyboard-only navigation.

## Downloads

Get the files from the [Releases page](https://github.com/MikeyMike99/JOSHY-downloads/releases/latest).

| File | Purpose |
| :--- | :--- |
| `JOSHY-Setup.exe` | Windows installer (recommended). |
| `JOSHY.exe` | Portable version. No installation needed. |

## Verify your download

SHA-256 checksums are listed in [SHA256SUMS.txt](SHA256SUMS.txt). In PowerShell, run `Get-FileHash .\JOSHY-Setup.exe -Algorithm SHA256` and compare the result.

## Core hotkeys

| Action | Shortcut |
| :--- | :--- |
| Play / Pause | Space |
| Volume up / down | ] and [ |
| Jump to search | E or Ctrl+F |
| Help and orientation | F1 |
